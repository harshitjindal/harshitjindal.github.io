Problem Statement

Using AWS lambda, write a program to monitor an S3 Uri. Whenever a user uploads data into the S3 storage, the program should capture the details. At the end of the day the program must send out an email to select users displaying the following information

  1. S3 Uri
  2. Object Name
  3. Object Size
  4. Object type

In addition to the above, the program should create a thumbnail and store it in a different uri in case the user uploads an image (.jpg/jpeg/png)

Steps

Create an account

In order to sign up for an account, go to https://console.aws.amazon.com and click “Create a new AWS account”. Provide the required information such as the email address, account name and payment information. Once the account is created, we should be able to log in to the console and proceed with the next steps.

Create two S3 buckets

An S3 bucket is a container for objects stored in Amazon. An object is a file and any metadata that describes that file. To store an object in Amazon S3, you create a bucket and then upload the object to a bucket. You can store any number of objects in a bucket and can have up to 100 buckets in your account. 1

To create a new bucket, navigate to “S3” under AWS services, and click on “Create bucket”.

For the purpose of this assignment, two buckets have been created in the Asia Pacific - Mumbai region (ap-south-1):

  • cc-ns-2022mt93524--cloud-computing-assignment1: The S3 bucket to be monitored
  • cc-ns-2022mt93524--cloud-computing-assignment1-thumbnails: The S3 bucket to store thumbnails in case an image is uploaded to the monitored bucket

In order to upload a new file to the monitored bucket, the “Upload” button can be used which is visible once a bucket is opened by clicking on the bucket name.

Create an IAM role

AWS Identity and Access Management (IAM) is a web service that helps you securely control access to AWS resources. With IAM, you can centrally manage permissions that control which AWS resources users can access. You use IAM to control who is authenticated (signed in) and authorized (has permissions) to use resources. 2

A correctly configured IAM role will enable the lambda function we will create later to access our S3 buckets, as well as Amazon Simple Email Service to send emails. To create a new role, look for “IAM” under AWS services, and click on “Roles”.

Proceed with “Create new role”, and select the following configuration:

  • Trusted Entity Type: AWS Service
  • Use case: Lambda
  • Permisions policies: AmazonS3FullAccess and AmazonSESFullAccess

For the purpose of this assignment, a role cc-ns-2022mt93524--cloud-computing-assignment1-lambda-s3-role has been created with the aforementioned permissions policies.

Configure SES

Amazon Simple Email Service (SES) is a cloud email service provider that can integrate into any application for bulk email sending. You can use Amazon SES to send marketing emails such as special offers, transactional emails such as order confirmations, and other types of correspondence such as newsletters. With Amazon SES, you pay based on the volume of emails sent and received. 3.

To configure SES, navigate to Amazon Simple Email Services under AWS Services, and click on “Create Identity”. I have chosen “Email Address” under “Identity Type”, and proceeded to verify aws@harshitjindal.com on my personal domain https://harshitjindal.com.

This would let the Lambda function to send/receive emails using aws@harshitjindal.com.

Set up a Lambda function

AWS Lambda is a serverless, event-driven compute service that lets you run code for virtually any type of application or backend service without provisioning or managing servers. You can trigger Lambda from over 200 AWS services and software as a service (SaaS) applications, and only pay for what you use. 4

Create the function

Similar to how we created S3 buckets, and an IAM role, to create a lambda function, head to “Lambda” under AWS services and click on “Create function”. Proceed to provide a name, runtime evironment language, architecture, and the existing IAM role name that was created in the previous step.

Set up a trigger

For this assignment, cc-ns-2022mt93524--cloud-computing-assignment1-lambda-function has been created with Python 3.9 runtime and x86_64 architecture. To continue setting it up, click on the function name so we land on the screen that lets us configure the function and write the code for it.

The goal of this lambda function is to execute the provided code when it is triggered by the monitored S3 bucket. To do this, the first step is to add a trigger to the lambda function, which can be done by clicking “Add trigger” button, and proceed to provide the service as “S3”, and the bucket name that needs to be monitored.

Once the trigger has been set, the S3 bucket is now being “monitored”, ie: any upload to it will trigger this lambda function. All that is remaining now is the code that will drive the functionality, including identifying the type of upload, creating a thumbnail and storing it in the thumbnails bucket if the object is an image, and then triggering an email with the required information such as Object Uri, name, size and type.

Write the code

# imports

import os, json
import boto3
import mimetypes
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
from email.mime.image import MIMEImage

# setting up `s3_client` and `ses_client`
s3_client = boto3.client('s3')
ses_client = boto3.client('ses')

def lambda_handler(event, context):
    
    # create `message` object
    message = MIMEMultipart()
    message['From'] = 'aws@harshitjindal.com'
    message['To'] = 'aws@harshitjindal.com'
    
    # iterate over all records in the `event` object
    for record in event['Records']:
        bucket_name = record['s3']['bucket']['name']
        thumbnail_bucket_name = "cc-ns-2022mt93524--cloud-computing-assignment1-thumbnails"
        object_key = record['s3']['object']['key']
        object_size = record['s3']['object']['size']
        
        response = s3_client.head_object(Bucket=bucket_name, Key=object_key)
        object_type = response['ContentType']
        
        # Check if object is an image, and if it is, create a thumbnail and store it in 
        # `thumbnail_bucket_name` (cc-ns-2022mt93524--cloud-computing-assignment1-thumbnails)
        if object_key.lower().endswith(('.jpg', '.jpeg', '.png')):
            
            # Create thumbnail
            s3_object = s3_client.get_object(Bucket=bucket_name, Key=object_key)
            image_content = s3_object['Body'].read()
            
            image_type = mimetypes.guess_type(object_key)[0]
            if not image_type:
                image_type = 'application/octet-stream'
            image = MIMEImage(image_content, _subtype=image_type.split('/')[1])
            # message.attach(image)
            
            # Upload thumbnail to S3
            thumbnail_key = os.path.splitext(object_key)[0] + '_thumbnail.jpg'
            s3_client.put_object(Body=image_content, \
                                Bucket=thumbnail_bucket_name, \
                                Key=thumbnail_key)
                                
            message['Subject'] = 'S3 Image Object Uploaded'
            message_body = f"S3 Uri: s3://{bucket_name}/{object_key}\nObject Name: {object_key}\nObject Size: {object_size}\nObject Type: {object_type}\n\nImage thumbnail with name \'{thumbnail_key}\' has been pushed to bucket \'{thumbnail_bucket_name}\'"
        else:
            message['Subject'] = 'S3 Regular Object Uploaded'
            message_body = f"S3 Uri: s3://{bucket_name}/{object_key}\nObject Name: {object_key}\nObject Size: {object_size}\nObject Type: {object_type}"

        # Send email
        
                        
        message.attach(MIMEText(message_body))

        email_response = ses_client.send_raw_email(
            Source=message['From'],
            Destinations=[message['To']],
            RawMessage={
                'Data': message.as_string()
            }
        )
        
        return {
            'statusCode': 200,
            'body': json.dumps(f"Email response status: {email_response}")
        }
